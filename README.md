# PBC-net: Photobleaching Correction for Single-Frame Computational Super-Resolution

This repository contains the custom Python code for **PBC preprocessing**, **PBC+RL reference generation**, **PBC-net training and inference**, **synthetic microtubule simulation**, and **image analysis** described in the manuscript.
